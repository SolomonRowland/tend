# Tend

A household maintenance app for the phone: recurring home, vehicle, health and family tasks, kids' well visits, a calendar, and the contacts you call for them.

- **Tend Home** (`home/`) is the app. One shared list for everyone in the household, live sync between phones, photos, and a daily heads-up notification. See `home/README.md`.
- The site's main address opens Tend Home. The original phone-only app is kept at `classic/` as a backup.
- Installs to the iPhone home screen (open in Safari › Share › Add to Home Screen) and works offline.
- No personal data lives in this repository.
