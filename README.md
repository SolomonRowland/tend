# Tend

A simple household maintenance app for the phone: recurring home, vehicle, health and family tasks, kids' well visits, a calendar, and the contacts you call for them.

- Installs to the iPhone home screen (open in Safari › Share › Add to Home Screen) and works offline.
- Your list is stored only on your phone. Use **Settings › Save a backup file** regularly.
- No personal data lives in this repository; load your own Tend file on first launch.
